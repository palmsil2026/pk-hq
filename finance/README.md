# 💵 แอปการเงินโรงขวด

แอปฝ่ายการเงินสำหรับเช็คเงินจ่ายบิล — ใช้ **ชีทเช็คบิลตัวเดิม** เป็นหลังบ้าน ไม่ย้ายข้อมูลไปไหน
([ชีทตัวจริง](https://docs.google.com/spreadsheets/d/1OXqLgj4xUNJTXE6g5fPI4fPVRx599pLpzZU6EV9VDxE/edit))

## ปัญหาเดิม → สิ่งที่แอปแก้

| เดิม | ใหม่ |
|---|---|
| จดบิลลงแท็บ "บัญชีส่งเงิน" แล้วต้อง**คัดลอกมือ**ไปแท็บ "รายการเครดิต" อีกรอบ | จดบิลครั้งเดียว → มียอดเครดิต = ขึ้นรายการค้างจ่าย**อัตโนมัติ** |
| ลูกค้าจ่ายเครดิต ต้องไล่หาบิลในแท็บเครดิตแล้วแก้สถานะเอง | ค้นชื่อลูกค้า → ติ๊กเลือกบิล (หลายใบพร้อมกันได้) → กด "รับชำระ" จบ |
| อยากรู้ยอดค้างรวม/ยอดเดือนนี้ ต้องนั่งรวมเอง | หน้าสรุปคำนวณให้สด ๆ: เงินเข้า แยกช่องทาง เครดิตค้างสะสม รายวัน |
| ข้อมูลเก่ากระจายอยู่หลายแท็บ หลายรูปแบบวันที่ | ปุ่ม "นำเข้าข้อมูลเก่า" รวมทุกแท็บเข้าที่เดียว (แท็บเดิมไม่ถูกแก้) |

ข้อมูลทั้งหมดอยู่ในแท็บใหม่ **`App_Bills`** ในชีทเดิม (บิล 1 ใบ = 1 แถว) —
เปิดชีทดู/กรอง/ทำกราฟเองต่อได้ตามปกติ นี่คือจุดซิงก์เดียวตามหลัก
"ระบบแยกออกจากกัน แต่ดาต้าซิงก์กันเหมือนเป็นหนึ่งเดียว"

## โครงไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าแอป (เสิร์ฟจาก GitHub Pages: `palmsil2026.github.io/pk-hq/finance/`) |
| `gas/Code.gs` | หลังบ้าน — **โปรเจกต์ GAS แยกของตัวเอง** ห้ามวางปนกับ GAS เลขา/โรงน้ำ/Old Days |

## ติดตั้งครั้งแรก (คุณปาล์มทำเอง ~10 นาที)

1. เปิด [script.google.com](https://script.google.com) → **New project** → ตั้งชื่อ `Bottle Finance`
2. ลบโค้ดเดิม แล้ววางทั้งไฟล์ `gas/Code.gs` **จาก branch `main`**
3. Project Settings (⚙️) → เลื่อนลง **Script Properties** → เพิ่ม 2 ตัว:
   - `SPREADSHEET_ID` = `1OXqLgj4xUNJTXE6g5fPI4fPVRx599pLpzZU6EV9VDxE`
   - `APP_KEY` = รหัสเข้าแอป (ตั้งเอง — แล้วค่อยส่งลิงก์ `?key=รหัสนี้` ให้ฝ่ายการเงิน)
   - แนะนำตั้ง Time zone ของโปรเจกต์เป็น Bangkok ด้วย (Project Settings ด้านบน)
4. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone**
   (ครั้งแรกเท่านั้นที่ใช้ New deployment — หลังจากนี้แก้โค้ดต้อง **Manage deployments → ✏️ → New version** เหมือนระบบอื่น ไม่งั้น URL เปลี่ยน)
5. คัดลอก URL ที่ลงท้าย `/exec` มาวางใน `index.html` บรรทัด `const GAS_URL = "PASTE_GAS_URL_HERE"` → commit + push `main`
6. เปิด `https://palmsil2026.github.io/pk-hq/finance/?key=รหัสที่ตั้ง`
   - เข้าครั้งแรกแล้วรหัสจำในเครื่อง เปิดครั้งต่อไปไม่ต้องใส่ key ใน URL อีก
7. ไปแท็บ **⚙️ อื่น ๆ → สแกนดูก่อน** → ตรวจตัวเลขว่าสมเหตุสมผล → **นำเข้าจริง**
   ข้อมูลเก่าทุกแท็บจะเข้ามาอยู่ใน `App_Bills` (กดซ้ำได้ ไม่นำเข้าซ้ำ / แท็บเดิมไม่ถูกแตะ)

## กติกาข้อมูล

- แอปเขียนเฉพาะแท็บ `App_Bills` เท่านั้น — แท็บเก่าทั้งหมดเป็น read-only ตลอดไป
- ห้ามลบ/เปลี่ยนชื่อหัวตารางของ `App_Bills` (โค้ดหาคอลัมน์จากชื่อหัว จะเพิ่มคอลัมน์ใหม่ต่อท้ายได้ ไม่พัง)
- สถานะเครดิตมี 2 ค่า: `ค้างจ่าย` / `จ่ายแล้ว` — แอปตั้งให้เองจากยอดเครดิต
- วันที่ในระบบเป็น `YYYY-MM-DD` (ข้อมูลนำเข้าจากรูปแบบเดิม เช่น "2/04" ถูกแปลงให้ พร้อมเดาปีจากบริบท —
  แถวไหนเดาไม่ได้จะถูกข้ามและรายงานตอนสแกน ไม่นำเข้ามั่ว)
- แก้ `gas/Code.gs` เมื่อไหร่ → bump `CODE_VERSION` บนหัวไฟล์ แล้วเช็คด้วยปุ่ม "🩺 เช็คระบบ" ในแอปว่าของจริงตรงกับ repo
