## ทำไมต้องมีไฟล์นี้

ก่อนหน้านี้ข้อมูลสินค้าโรงขวด **ไม่มีทะเบียนกลางเลย** — กระจายอยู่ใน:
- บิลเงินสดเขียนมือ (ชื่อสินค้าเขียนย่อไม่ซ้ำแบบกัน เช่น "250 ml เรียบใส" / "ขวด 250 มล.(เพชร)ฟ้า")
- ชีตบัญชี "ระบบบัญชี" (เก็บแค่ยอดเงินต่อบิล **ไม่มีรายการสินค้า**)
- ชีตโรงน้ำ OriginSystem (ฝั่งเราซื้อขวด/ฝา/ฟิล์มจากโรงขวด เลยมีชื่อวัตถุดิบอยู่ส่วนหนึ่ง)
- สมุดราคา + ความจำของหน้างาน

ไฟล์ชุดนี้รวบทั้งหมดเป็น **ทะเบียนสินค้ามาตรฐานชุดเดียว** พร้อมโครงหมวดหมู่ใหม่ เอาไปวางเป็นแท็บ `Products` ในชีต **P&KSystem** (ชีตใหม่ที่เพิ่งสร้าง) ได้ทันที

## 🗂️ หมวดหมู่ใหม่ (6 หมวด)

| รหัสหมวด | หมวด | ตัวอย่างสินค้า | หน่วยขายหลัก |
|---|---|---|---|
| `BOT` | ขวด PET | ขวดใส/สี ทรงเรียบ เพชร MK ขนาด 250–1500 ml | ใบ / ถุง |
| `CAP` | ฝา | ฝาน้ำ PET 7 สี, ฝาทอง, ฝาต๊อก | ชิ้น |
| `FLM` | ฟิล์ม | ฟิล์มคอขวด (ปากกว้าง/แบบถัง), ฟิล์มแพ็คโหล, ฟิล์มฝาถ้วย | ม้วน |
| `TNK` | ถัง/แกลลอน | ถังแกลลอน (คาดว่า 20 ลิตร) | ใบ |
| `CUP` | ถ้วยน้ำ | ถ้วยแก้วสำหรับน้ำถ้วย | ลัง/แพ็ค (รอยืนยันหน่วย) |
| `MSC` | อื่น ๆ / งานสั่งพิเศษ | PVC ตัดตามขนาด, หลอดพรีฟอร์ม (ขายยกกระสอบ) | ตามงาน |

### คุณลักษณะ (attribute) ของขวด — แกนที่ใช้แยก SKU

ขวด 1 ตัว แยกด้วย 4 แกน: **ขนาด × ทรง × สี × งานพิมพ์**

- **ขนาด**: 250 / 500 / 600 / 1500 ml (ที่พบหลักฐานแล้ว — บิลระบุช่วง "250–1500ML")
- **ทรง**: เรียบ · เพชร · MK · (มีอีกทรงในบิลอ่านได้ว่า "OK" — รอคุณปาล์มยืนยันชื่อจริง)
- **สี**: ใส · ฟ้า (พบ 2 สี อาจมีมากกว่านี้)
- **งานพิมพ์**: ไม่สกรีน · สกรีนแบรนด์ลูกค้า (เช่น เพียวซ่า, บุญวาทย์)

## 🏷️ กติกาตั้งรหัส SKU

```
PK-<หมวด>-<ขนาด/สเปค>-<ทรง/แบบ>-<สี>
```

- ทรง: `RB`=เรียบ, `DM`=เพชร, `MK`=MK · สี: `CL`=ใส, `BL`=ฟ้า, `NV`=น้ำเงิน, `GD`=ทอง ฯลฯ
- งานสกรีนต่อท้ายด้วยชื่อแบรนด์: `-SC-PURESA`
- ตัวอย่าง: `PK-BOT-600-RB-CL` = ขวด PET 600ml ทรงเรียบ ใส
- **รหัสตั้งแล้วห้ามเปลี่ยนความหมาย** — เพิ่มสินค้าใหม่ = เพิ่มแถวใหม่ เลิกขาย = เปลี่ยนสถานะ ไม่ลบแถว

## 📖 พจนานุกรมคอลัมน์ของ `products-master.csv`

| คอลัมน์ | ความหมาย |
|---|---|
| `SKU` | รหัสสินค้ามาตรฐาน (กติกาข้างบน) |
| `หมวด` | BOT / CAP / FLM / TNK / CUP / MSC |
| `ชื่อสินค้า` | ชื่อเต็มมาตรฐาน ใช้ในบิล/ระบบ/รายงานให้เหมือนกันทุกที่ |
| `ขนาด` | ปริมาตร (ml) หรือสเปค เว้นว่างถ้าไม่เกี่ยว |
| `ทรง/แบบ` | ทรงขวด หรือแบบของฟิล์ม/ฝา |
| `สี` | สีของสินค้า |
| `หน่วยขาย` | หน่วยที่ออกบิล (ใบ/ชิ้น/ม้วน/ถุง/กระสอบ/ชุด) |
| `จำนวนต่อหน่วยใหญ่` | เช่น ขวด 600ml = 200 ใบ/ถุง (จากบันทึกเบิกจริงฝั่งโรงน้ำ) |
| `ราคาอ้างอิง(บาท)` | ราคาต่อหน่วยขายที่เห็นในบิลจริงล่าสุด — **ราคาขายจริงอาจต่างตามลูกค้า/ปริมาณ** |
| `สถานะข้อมูล` | `ยืนยันแล้ว` = มีหลักฐานชัด · `รอยืนยัน` = อ่านจากลายมือ/ต้องถามหน้างาน |
| `ที่มา` | หลักฐานที่พบ (บิลวันที่เท่าไหร่ / ชีตไหน) |
| `หมายเหตุ` | ข้อสังเกต สิ่งที่ต้องเช็คต่อ |
