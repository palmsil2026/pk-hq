## ปัญหาที่เจอ (เรียงตามความสำคัญ)

1. **ไม่มีทะเบียนสินค้า/รหัสสินค้าเลย** — สินค้าตัวเดียวกันถูกเรียกต่างกันตามคนเขียนบิล เช่น ขวด 250 เรียบใส เขียนเป็น "250 ml เรียบใส", "ขวา 250 มล.", "ขวด 250ml" → แก้ด้วย `products-master.csv` (ตั้ง SKU + ชื่อมาตรฐานแล้ว)
2. **บัญชีเก็บแค่ยอดเงิน ไม่เก็บรายการสินค้า** — ตอบไม่ได้ว่าเดือนนี้ขายขวดขนาดไหนไปเท่าไหร่ สินค้าไหนทำเงิน → ตอนวางระบบขายใน P&KSystem ให้บันทึกออเดอร์ **อ้าง SKU เสมอ**
3. **ราคาไม่มีตารางกลาง** — อยู่ในสมุด+ความจำ ราคาในบิลเดือนเดียวกันก็แกว่ง (เช่น ขวด 600: 1.43 / 1.95 / 2.20 แล้วแต่รวมฝา/ทรง/ลูกค้า) → ควรทำตารางราคามาตรฐาน + ส่วนลดตามปริมาณ ให้คุณพ่อ/หน้างานเคาะ
4. **หน่วยขายปนกัน** — ใบ / ชุด(ขวด+ฝา) / ถุง / ม้วน / กระสอบ / "สีละ 200" — บิลไม่ระบุหน่วยชัด → ทะเบียนใหม่กำหนดหน่วยขายต่อ SKU แล้ว แต่ต้องให้หน้างานยืนยันบางตัว
5. **ชื่อลูกค้าในบัญชีสะกดหลายแบบ ไม่มีรหัสลูกค้า** (578 ราย) — เช่นเดียวกับที่ฝั่งโรงน้ำเจอ "วรินธร/วรินทร/น้ำดื่มวรินธร" เป็นคนเดียวกัน → งานถัดไป: ทะเบียนลูกค้า + รหัส
6. **สรุป OCR ของเลขาอ่านลายมือผิดได้** — เช่น "ฟิล์มคอขวด/ปากกว้าง" ถูกสรุปเป็น "ฟิล์ม/ปากขวด", "ถ้วยแก้ว" เป็น "ถ้อยแก้ว" → ข้อมูลที่เข้าคลังจากรูปบิลควรมีคนเช็คซ้ำ หรือให้บิลพิมพ์ชื่อจาก SKU ไปเลย

## แถวที่ติดธง `รอยืนยัน` ใน CSV — รอคุณปาล์ม/หน้างานชี้ขาด

- ชื่อทรงขวดที่อ่านได้ว่า **"OK"** (ขวด 600 ใส @1.43) — ชื่อจริงคืออะไร
- **ฝาต๊อก vs ฝาดำ** (บิล 19/8/69 ลายมือกำกวม)
- **ถังแกลลอน** — ใช่ถัง 20 ลิตรมาตรฐานไหม มีฝา/ไม่มีฝา
- **ถ้วยแก้ว @520** — หน่วยเป็นลังหรือแพ็ค บรรจุกี่ใบ
- **หลอดพรีฟอร์ม @735/กระสอบ** — ขายให้ลูกค้าภายนอกจริงหรือเป็นรายการภายใน
- **ขวดสกรีน** — โรงขวดสกรีนเอง หรือส่งช่วงร้านสกรีน
- ราคาที่ยังว่าง: ขวด 250/600 MK ใส, ขวด 500 เรียบ, ขวดสกรีนทุกตัว, ฟิล์มแพ็คโหล
- มีขวดขนาด/ทรง/สีอื่นที่ยังไม่โผล่ในบิล 8 ใบนี้ไหม (เช่น 350ml, 950ml, ขวดขุ่น) — บิลหน้าสมุดเห็นเศษตัวเลข "ขาว/แดง … 17x…" น่าจะมีของอีกหลายตัวในสมุดราคา

## หมายเหตุฝั่งโรงน้ำ (เกี่ยวข้องกัน แต่เป็นงานของแชท origin-hq)

ระหว่างตรวจ เจอว่าแท็บ `Products` ของโรงน้ำเองก็มีปัญหาคล้ายกัน: ขนาดไม่มีหน่วย ("600" เฉย ๆ ในแถววรินธร), แบรนด์ OEM สะกดสองแบบ (วรินธร/น้ำดื่มวรินธร — ในออเดอร์มี "วรินทร" อีก), คอลัมน์ราคาว่างทั้งหมด, สต๊อกติดลบทุกตัว, แบรนด์ OEM ในออเดอร์ (นิวสกาย/ทิพยา/ต้นโพธิ์/ล้านนา) ไม่มีในตารางสินค้า — **จดไว้ให้เฉย ๆ ห้ามแก้จาก palm-hq** ให้ส่งต่อแชท `origin-hq` ตามกติกา
