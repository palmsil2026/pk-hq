- ออฟฟิศ: ~8–9 รายการ/วัน (จ–พฤ มากกว่า ศ–ส) · 1.34 รายการ/ใบ · วันส่ง +10 วันอัตโนมัติ 97.9% · หมายเหตุมีข้อความ 74% (90 วันล่าสุด 86%)
- ทีมเป่า: เปิดรอบภายใน ±30 นาทีของเวลาเปิดเครื่องจริง 69% · ลงล่วงหน้า 7% (กะดึก) · ย้อนหลังเกิน 3 ชม. 4% · B กรอก 42% · เสีย 59% · หมายเหตุรอบ 8% · ชื่อคนพิมพ์เอง สะกดหลายแบบ · รอบค้าง 70
- ทีมสกรีน: กดงาน 96–97% ของออเดอร์สกรีนที่ส่งแล้ว · 51% ของการกดอยู่ 8:00–8:59 · 73% กดเป็นชุดติดกัน (≥3 ครั้งใน 3 นาที) · **งานหลายวันกดซ้ำ = ตัดเต็มจำนวนซ้ำ** (25% ของงาน · เกินจริง 11.1 ล้านใบตั้งแต่ มี.ค. 69) · "เสร็จ dd/mm/yy + ชื่อ" พิมพ์ลงหมายเหตุ 3,810 ออเดอร์
  · 60 วัน (นับงานละครั้ง): 401 งาน 2.33 ล้านใบ ≈ 272,000 ใบ/สัปดาห์ · วันทำงานกลาง ~43,000 ใบ · ออเดอร์ → เริ่มสกรีน กลาง 4 วัน · เริ่ม → เสร็จ ส่วนใหญ่วันเดียวกัน/วันรุ่งขึ้น
- บัญชี: ~8 บิล/วัน · ลงเป็นชุด ช้ากว่าวันจริง ~1 สัปดาห์

## 4. ต้องเพิ่มใน v2 ก่อนย้ายทีม (coverage gap)

1. **สกรีนทำบางส่วน** — การ์ดงานมีปุ่ม "ทำวันนี้ … ถุง" (ไม่บังคับ) → ตัดสต๊อกเท่าที่ทำ ที่เหลือค้างในคิว สถานะ `เตรียมการสกรีน` ต่อ · กด "เสร็จ" ทีหลัง = ที่เหลือทั้งหมด · ย้อนได้ทีละครั้ง · สรุปเย็นต่อทีมนับรวมยอดบางส่วน
2. **ออฟฟิศ › ออเดอร์ รวมตามสินค้า** — ต้นไม้ ประเภท → ขนาด → สี → ใบสั่ง ยอดรวม (ใบ + ถุง) ทุกชั้น เฉพาะที่ยังไม่จบ (v1 ใน `index.html` มีแล้ว ใช้เป็นแบบ)
3. **ยอดมัดจำ** ในออเดอร์ (เงิน · ช่องทาง · วันที่) — เห็นเฉพาะบทบาทที่เห็นเงิน
4. **ต้องการเมื่อไร + งวดส่ง + ยังไม่ปล่อยเข้าคิว** (สเปกใน `PLANNING.md` §3)
5. ปุ่ม **แชร์ลงไลน์** ตอนจอดเครื่อง/ซ่อมเสร็จ (ข้อความสั้น ไม่มีรหัสระบบ)
6. นำเข้ารอบผลิตเดิม **อัตโนมัติทุกวัน** ช่วงเปลี่ยนผ่าน (ตอนนี้ต้องกดในหน้าประธาน)
7. หน้ารวม **รายการซื้อหน้าร้าน** (ออเดอร์ประเภท "ขายหน้าร้าน")

## 6. ต้องถามหน้างาน (ข้อมูลตอบไม่ได้)

1. จัดสายส่งวันพฤหัสด้วยอะไร ส่งให้ใครดู
2. ใบส่งของ/บิล (เลขที่ขึ้นต้น ORNM มีรหัสลูกค้า) พิมพ์จากโปรแกรมอะไร ใคร ตอนไหน
3. Checker คือใคร ตรวจกับอะไร · คนขับเก็บเงินสดไหม · บิลกลับมาที่ใคร
4. ใครพิมพ์ "เสร็จ … ชื่อ" ลงหมายเหตุ
5. ทีมสกรีนกดตอน 8 โมง = เบิกขวดวันนี้ หรือกดย้อนของเมื่อวาน
6. ใบบันทึกการผลิตแผนกสกรีนใช้คิดค่าแรงรายชิ้นไหม (ถ้าใช่ แอปต้องแทนหน้าที่นี้ — ค่าแรงอยู่ P&K HR)
7. ผู้รับออเดอร์ "เซลล์" / "คนอื่น" คือใคร ใช้เครื่องไหน · แต่ละจุดใช้มือถือส่วนตัวหรือแท็บเล็ตกลาง
