- ขวดสกรีนแล้วเป็นกุญแจแยก `spec:<สเปก>|สกรีน <สี>` (ไม่ปนขวดเปล่า · ขึ้นรถรายการที่มีสกรีนตัดจากกุญแจนี้) · สีเกรด B ตัดจากสต๊อกเกรด B
- **ขึ้นรถ = ออกจากคลัง** · ของบนรถ = แถว `delivery_loads` (บนรถ/ส่งไม่ได้) · ส่งแล้ว = ไม่ตัดซ้ำ · เอาลง = คืนเข้ากุญแจเดิม · ติดลบ = ธง (ครั้งเดียวต่อกุญแจจนกว่าปิด) ไม่บล็อก
- ส่งไม่ได้ = ของยังอยู่บนรถ (ไม่คืนคลังเอง) · ส่งบางส่วน = ที่เหลืออยู่บนรถ · ออเดอร์ที่ส่งไม่ครบค้างเป็นงวดถัดไปในหน้าเส้นทาง
- ขึ้นเกินออเดอร์ / ขึ้นก่อนสกรีนเสร็จ = ทำได้ + เหตุผล + ธง (ไม่มีทางตัน) · ออฟฟิศทำแทนทีมสกรีน/คนขับได้ (ไม่มีชนชั้น · มีประวัติ)
- รถ 1 คัน 1 วัน = 1 รอบส่ง (`T<วัน>-<คัน>`) · ยังไม่ผูกคนขับกับรอบ (คนขึ้น/คนส่งอยู่ในแถวของบนรถ)
- ใบส่งของ/ส่งแล้ว **ไม่มียอดเงิน** (ขยายการเห็นเงินต้องถามก่อน §9) — บอกแค่ "ออเดอร์นี้มีบิลแล้ว"
- ออเดอร์ตัวอย่าง/นำเข้า (ไม่ใช่ v2) สถานะไม่ไหลตามการส่ง — กติกาเดียวกับออฟฟิศ
- ย้อน = ย้อนได้เฉพาะรายการล่าสุดของแถวนั้น (กติกากลาง: ทุกแถวต้องยังเป็นรุ่นเดิม) — ส่งต่อแล้ว/แก้จำนวนแล้ว ย้อนอันก่อนไม่ได้ ต้องทำรายการแก้ (เอาลงจากรถ ฯลฯ)

**ยังไม่ได้ทำ / คำถามคุณปาล์ม**
- เงิน: ยังไม่มีรับเงินในหน้าส่งของ — **คนขับเก็บเงินสดจากร้านไหม** (ถ้าใช่: ช่องรับเงินตอนกดส่งแล้ว ผูก `stop_id` ไม่มีค่าตั้งต้น) · ทีมส่งของควรเห็นยอดในบิลไหม
- ทีมสกรีนกี่คนต่อทีม ต้องจดชื่อคนในทีมไหม · ขวดสกรีนเสียทิ้งเลยหรือเป็นเกรด B (ตอนนี้ = ออกจากสต๊อกเฉย ๆ)
- รถออกหลายรอบต่อวันไหม · แก้ทะเบียนรถจากหน้าจอ (ตอนนี้แก้ที่ตาราง `vehicles` — หน้าประธานยังไม่มีปุ่ม)
- เลื่อนวันส่งเมื่อลูกค้าขอเลื่อน = ออฟฟิศแก้ออเดอร์ (ธง "ส่งไม่ได้" แจ้งให้) · หน้า "ส่งของ" ของแอปออฟฟิศใช้ `views` ที่ `deliver.js` export ไว้ได้
- ยังไม่ได้ลองบนมือถือจริง/ข้อมูลจริง · พิมพ์ (window.print) ทดสอบแค่ว่าเปิดได้ ยังไม่เคยพิมพ์ออกเครื่องจริง
