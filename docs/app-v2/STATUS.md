- ตำแหน่งเครื่องในผังเป็นร่าง (`v2/db/reference/factory.json`) รอผังจริง

**สิ่งที่คุณปาล์มต้องทำเอง** (ตอนพร้อมเปิดใช้ — ยังไม่ต้องรีบ)
1. อนุมัติให้ `gas/Code.gs` รุ่น `2026-11-16v2` ขึ้น `main` (เพิ่มสะพานอย่างเดียว action เดิมเหมือนเดิม — มีเทสต์ยืนยัน) → deploy อัตโนมัติเหมือนทุกครั้ง
2. Apps Script editor › รัน `v2ShowKeys()` ครั้งเดียว → ได้กุญแจ 2 ดอก (`PK_TICKET_KEY` · `PK_SYNC_KEY`) — **ห้ามวางในแชท**
3. GitHub › Settings › Secrets: ใส่ `CLOUDFLARE_API_TOKEN` · `CLOUDFLARE_ACCOUNT_ID` (บัญชีเดียวกับโรงน้ำได้ — ชื่อโปรเจกต์/ฐานขึ้นต้น `pk-` แยกกัน) + `PK_TICKET_KEY` · `PK_SYNC_KEY` จากข้อ 2 → push ครั้งถัดไปขึ้นพรีวิวเอง
4. (ถ้าจะนำเข้ารอบผลิตเก่า) Script Properties › `LEGACY_STOCK_SHEET_ID` = id ชีต Stock Management
5. ตรวจว่าทุกคนในชีต Staff มี "แผนก" ตรงชื่อ: ออฟฟิศ · ผลิต · สกรีน · ส่งของ · บัญชี · บริหาร (คุณปาล์มเองต้องมีแถวแผนก "บริหาร" + PIN ถึงจะเข้าหน้าประธาน v2 ได้)

**คำถามที่ตัดสินแทนไว้** (แก้ได้ · บอกคุณปาล์มตอนตื่น)
- ทีมผลิต: มือถือหน้าเครื่องใส่ PIN ครั้งเดียวตอนตั้งเครื่อง (ใช้ดูข้อมูล) · ทุกครั้งที่กดบันทึกถาม "ใครบันทึก" + PIN (ตั๋ว 5 นาที) — คนบันทึก = คนที่ใส่ PIN ตอนกด ไม่ใช่คนตั้งเครื่อง
- ประธานเปิดแอปทุกทีมได้และทำแทนได้ (audit จดว่าในนามทีมไหน)
- ย้อนได้ 24 ชม. (ค่าตั้ง `UNDO_HOURS`) หรือจนขั้นถัดไปแตะ · ย้อนได้เฉพาะคนที่บันทึกหรือประธาน
- ราคาอ้างอิงจากบิลใน `products-master.csv` ไม่ถูกตั้งเป็นราคาขาย (ราคาตั้งโดยประธานเท่านั้น — §9)
- รอบผลิตค้างจากแอปเดิม = สถานะ "ค้างจากแอปเดิม" + ธง (ไม่นับเป็นเครื่องเดิน)
- ลูกค้าจับคู่ไม่ได้ = สร้าง "รอตรวจ" + ธง (ไม่ผูกเดา) · ชื่อย่อที่ตรงหลายรายถือว่ากำกวม ไม่จับ
- บิลลูกหนี้ที่ "จ่ายแล้ว" ในชีทบัญชีไม่มีวันที่ชำระจริง → ใช้วันที่บิล + จดหมายเหตุ
- สถานะว่าง/แปลกในชีต Staff = "พัก" ใน v2 (กันแอบเพิ่มคนผ่านชีต)

**คำถามที่ตัดสินแทนไว้** (แก้ได้ · ถามคุณปาล์มแบบภาษางาน)

- สาเหตุจอดใช้ชุดที่คุณปาล์มให้ (ชุดเดิมเก็บไว้ ไม่ลบ) · เปลี่ยนโมลด์ต้องปิดรอบก่อนกด "เริ่มเปลี่ยน"
- ปิดย้อนหลัง = เปิดนานเกิน 14 ชม. / ค้างจากแอปเดิม / เวลาปิดย้อนเกิน 60 นาที (ค่าตั้ง `RUN_STALE_HOURS` · `LATE_CLOSE_MIN`)
- ย้อนปิดรอบไม่ได้เมื่อของถูกส่ง/ใช้ไปแล้ว → "แก้ยอด" + เหตุผล · รอบเก่าจากแอปเดิมเป็นประวัติ ไม่แตะสต๊อก (สต๊อกเริ่มด้วยยอดยกมา/นับปรับ)
- รอบเก่าเวลาปิดก่อนเริ่ม: ≤ 20 ชม. (ค่าตั้ง `RUN_MAX_HOURS`) หรือตรง "เวลาทำงานสุทธิ" = กะดึก · อื่น = พิมพ์ผิด (เก็บยอด ไม่นับชั่วโมง · ธงสรุป 1 เรื่อง)
- รอบที่ยัง "กำลังผลิต" ในแอปเดิมและเพิ่งเริ่ม (≤ 14 ชม.) นับว่าเครื่องเดินบนผัง (ช่วงทีมยังลงแอปเดิม) · เก่ากว่านั้น = ค้าง
- จอดเครื่องไม่ผูกกับการปิดรอบ (ปิดรอบแล้วเครื่องยังจอดได้) · เปิดรอบใหม่บนเครื่องที่จอด = เดินต่อให้เอง

- รถ 1 คัน 1 วัน = 1 รอบส่ง (`T<วัน>-<คัน>`) · ยังไม่ผูกคนขับกับรอบ (คนขึ้น/คนส่งอยู่ในแถวของบนรถ)

- ออเดอร์ตัวอย่าง/นำเข้า (ไม่ใช่ v2) สถานะไม่ไหลตามการส่ง — กติกาเดียวกับออฟฟิศ
