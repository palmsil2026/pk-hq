**ยังไม่ได้ทำ / รู้ข้อจำกัด**
- รับเงินในบิล = แอปบัญชี (ออฟฟิศออกบิลอย่างเดียว) · แก้บิลหลังออก = ยกเลิกแล้วออกใหม่
- แก้สาย/แผนที่ลูกค้าได้แค่ช่องข้อความ (ยังไม่มีปักหมุด)
- ออเดอร์ที่ยังค้างในแอปเดิมตอนวันย้ายระบบ: ตอนนี้นำเข้าตามสถานะเดิม (มักเป็น "ส่งแล้ว") — ต้องเคาะวิธีย้ายวันจริง
- ข้อมูลสมมติในเครื่องทดสอบยังไม่มีราคาทะเบียนครบทุกสเปก · ยังไม่ได้ลองบนมือถือจริง

**คำถามที่ตัดสินแทนไว้** (แก้ได้)
- ลงออเดอร์แล้ว**ยังไม่เข้าคิวผลิตเอง** — มีขั้น "ส่งเข้าคิว" (สวิตช์ในการ์ดยืนยันเปิดไว้ ยกเว้นยังรอโอน/รอแบบ) กันโรงงานเป่าของที่ลูกค้ายังไม่จ่าย/แบบยังไม่ผ่าน
- สถานะออเดอร์ v2 คิดจากงานจริงเท่านั้น (ไม่มีปุ่มเปลี่ยนสถานะเอง)
- แก้ออเดอร์หลังเริ่มผลิต = ได้ แต่ต้องเหตุผล + ธงถึงทีมที่เริ่มแล้ว · เปลี่ยนสเปกหลังเริ่มผลิต = ไม่ได้ (ยกเลิกรายการ/ลงใหม่) · เพิ่มจำนวนหลังงานเสร็จ = งานผลิตเพิ่ม
- ยกเลิกหลังส่งไปบางส่วน = ตัดออเดอร์เหลือเท่าที่ส่ง สถานะ "ส่งแล้ว" · ของยังอยู่บนรถ = ยกเลิกไม่ได้ (เอาลงก่อน)
- ลูกค้ามารับเอง = การส่ง 1 ครั้งที่ไม่มีเที่ยวรถ ตัดสต๊อกจากของสกรีน/ขวดเปล่าตามสเปก · สีเกรด B ตัดจากบัญชี B · รับเกินที่สั่ง = เหตุผล + ธง
- บิลออฟฟิศ = `ค้างชำระ` เสมอ แม้เลือก "สด" (เงินเข้าจริงให้บัญชีลง) · ไม่มีค่าเริ่มต้น สด/เครดิต · 1 ออเดอร์ 1 บิล · เลขบิล `PK2-<ปี>-NNNN` (ไม่ชนกับเลขกระดาษเดิม)
- ราคาทะเบียนเลือกตามประเภทซื้อ: ขายราคาโรงงาน → ราคาโรงงาน · ขายหน้าร้าน → ราคาหน้าร้าน (ตรงกับบอร์ดประธาน)
- นำเข้าออเดอร์เก่า: ถ้าออฟฟิศแก้ใน v2 แล้ว แถวเก่าที่เปลี่ยนทีหลังไม่ทับ (แจ้งในผลนำเข้าแทน)

   ส่งของ: เส้นทางใช้วันของงวดที่ถึงคิว + ป้าย "งวด 2/3" · ขึ้นรถตั้งต้น "งวดนี้" (รวมส่วนขาด) เลือกทั้งหมด/บางส่วนเองได้
3. **มัดจำ** — ลงได้หลายครั้ง (บาท→สตางค์ · ช่องทางต้องเลือกเอง · วันที่ · หมายเหตุ) · ยกเลิก = เหตุผล · ออฟฟิศ/บัญชี/ประธานเท่านั้น (ทีมผลิต/สกรีน/ส่งของ 403) · หน้าออกบิล + หน้าบิลโชว์ "มัดจำแล้ว ฿X — ไม่หักให้เอง" · ออกบิลตอนมีมัดจำ = ธง "มีมัดจำ ตรวจตอนออกบิล" ถึงบัญชี
4. **หมุดลูกค้า** — (ก) แนะนำสายจากอำเภอ (เรียนจากทะเบียน ≥60% และ ≥2 ราย) ในหน้าลูกค้า "ใช้สาย X" + แผ่น "แนะนำสาย" ยืนยันทีละหลายราย · ไม่เขียนทับ (ข) วางลิงก์แผนที่/พิมพ์พิกัด → แกะ ?q= · /@ · !3d!4d · ?query= · ลิงก์ย่อ maps.app.goo.gl/share.google ตามทางต่อฝั่งเซิร์ฟเวอร์ (เฉพาะโดเมน Google ≤5 ทอด) · อ่านไม่ได้ = เก็บลิงก์ + ธง (ค) ส่งของกด "ส่งแล้ว" ที่ร้านไม่มีหมุด → "ปักหมุดร้านนี้" แตะเดียว GPS (ข้ามได้ · เก็บความแม่น · คลาดเกิน 200 ม. ไม่รับ) · หมุดเดิมแก้ได้ต้องมีเหตุผล + ธง (ง) `route_areas` ชื่อสายที่ทีมเรียก ↔ รหัส · ประธาน › ทีม › ชื่อสายส่ง: "เดาชื่อสายจากอำเภอ" (ธงรอยืนยัน) → ยืนยัน/แก้ · ชื่อสายขึ้นคู่รหัสในเส้นทางส่งของ
5. **ซื้อหน้าร้าน** — ออเดอร์ "ขายหน้าร้าน" ตามวัน (วันนี้/7/30 วัน) · รวมตามสินค้า (ใบ/ถุง) · ยอดตามราคาที่ลง + บอกรายการที่ยังไม่ใส่ราคา (ไม่เดา)

**ตัดสินแทนไว้** (แก้ได้)
- งวดเก็บเป็น "ส่วนของออเดอร์" — รายการหลายตัวแบ่งตามสัดส่วนเดียวกัน · "ต่อครั้ง" อิงรายการแรก · ส่งครบ/ไม่ครบคิดจากวันที่ส่งจริง (ส่งในวันเดียวกันนับเป็นงวดเดียว) ไม่มีปุ่มปิดงวด
- ทยอย: ส่งไปตั้งแต่วันที่นัดแล้ว = "รอนัดเที่ยวถัดไป" (ไม่โชว์เลยกำหนดผิด ๆ) · ครั้งเดียว: ส่งไม่ครบค้างในวันเดิม
- นัดครั้งแรกไม่ต้องมีสาเหตุ · เลื่อน/ยกเลิกนัด = สาเหตุบังคับ · ออเดอร์เก่าที่ไม่ได้วางงวด ใช้วันส่งเดิมเป็นงวดเดียว
- มัดจำ: ลงได้ทั้งออฟฟิศและบัญชี (สลิปมาทางไลน์ P&K PLASTIC) · ไม่บังคับ — ค่าตั้ง `DEPOSIT_REMIND` = "ไม่เตือน" (§9)
- หมุด: ไม่มีหมุดประมาณจากจุดกลางอำเภอ (ไม่มีข้อมูลพิกัดอำเภอใน repo และไม่ยิงบริการแผนที่ภายนอก) · GPS คลาดเกิน 200 ม. ไม่รับ
- ชื่อสายเดา = อำเภอที่พบบ่อยสุดในสาย (อันดับสอง ≥30% ต่อด้วย "–") · "เมือง…" ย่อเป็น "เมือง"

**ยังไม่ได้ทำ / ต้องรู้**
- กระดานสายส่ง 7 วัน (ปฏิทินหมุดสาย) · ขวดที่ต้องมี · มุมมองแผนที่ — ชั้นวางแผนขั้น 2 (มีหมุด/ชื่อสาย/วันงวดรองรับแล้ว)
- ออเดอร์ประจำโรงน้ำ · วันเร็วสุดที่ทำได้ตอนรับออเดอร์ · นับสาเหตุเลื่อนรายสัปดาห์บนหน้าประธาน (ข้อมูลเก็บแล้วใน `reschedule_events`)
- ตามลิงก์ย่อจริงยังไม่ได้ลองกับ Google จริง (เทสต์ใช้ทางต่อจำลอง) · GPS ลองแค่ในเบราว์เซอร์จำลอง ยังไม่ได้ลองมือถือจริง
- บัญชีเห็นมัดจำผ่าน action `office.deposits` แล้ว แต่หน้าแอปบัญชียังไม่โชว์ (ไฟล์ของโมดูลบัญชี)

**คำถามคุณปาล์ม** (§9 — ตั้งค่าได้ ยังไม่เป็นกติกาถาวร)
1. มัดจำบังคับไหม — ทุกออเดอร์ / เฉพาะงานสกรีนโลโก้ / ไม่บังคับ (ตอนนี้ไม่เตือน · เปลี่ยนที่ประธาน › ทีม › ค่าตั้ง)
2. ออกบิลแล้วมีมัดจำ — หักในบิลเลย หรือออกใบรับเงินแยก (ตอนนี้ไม่หัก + ธงให้บัญชี)
3. ขวดไม่พอใครได้ก่อน (ตอนนี้ระบบไม่จัดลำดับให้ — งวดที่นัดแล้วโชว์เด่นกว่าของจองเท่านั้น)
4. ของจองค้างกี่วันให้โทรยืนยัน (ตอนนี้ 14 วัน · ไม่ตัดเอง)
5. ชื่อสายที่ทีมเรียกจริง ↔ รหัสสาย — ถามหัวหน้าทีมสกรีนแล้วยืนยันในหน้าประธาน

- **ทีม**: รายชื่อตามสถานะ/แผนก (ยังไม่ยืนยัน · ยังไม่มี PIN) · **ตั้ง/รีเซ็ต PIN** (ใส่สองครั้ง) · **พักงาน/เปิดงาน/ลาออก** · ย้ายแผนก · **เพิ่มพนักงาน** · ยืนยันคนใหม่ — ทุกปุ่มเขียน**ชีต Staff ผ่าน Google** แล้วมีผลในแอปทันที (พัก = เข้าไม่ได้ทันที · PIN ใหม่ = ตั๋วเก่าตายทันที) · นำเข้าข้อมูล (ของ Foundation) · ค่าตั้ง (ชื่อภาษาคน · ซิงก์อัตโนมัติ เปิด/ปิด) · สถานะซิงก์ชีทบัญชี

**คำถามที่ตัดสินแทนไว้** (แก้ได้ · บอกคุณปาล์มตอนตื่น)
- **บิลจากชีทบัญชี รับชำระ/แก้ในชีทเท่านั้น** (ในแอปดูได้ + บอกเหตุผล) — ถ้ารับในแอปได้ด้วย ยอดจะอยู่ 2 ที่และซิงก์ทับกันเอง (ขัด "ห้ามมียอดเงินอยู่ 2 ที่" + ห้ามเขียนกลับชีท) · บิลในแอป (จากออเดอร์/ลงในแอปบัญชี) รับชำระในแอป
- **ลูกหนี้จากชีทนับจากแท็บลูกหนี้** · บิลเครดิตในแท็บบิลรายวันไม่นับเป็นลูกหนี้ (แท็บรายวันไม่มีสถานะการจ่าย — ถ้านับจะค้างตลอดกาลและซ้ำกับแท็บลูกหนี้) · มีบรรทัดบอกจำนวนบนจอ
- บิลใบเดียวกันอยู่ทั้งในแอปและในชีท → นับบิลในแอป (แถวชีทเป็น "ใบเดียวกัน") · ชีทจ่ายแล้วแต่แอปค้าง = งานรอตรวจให้บัญชีกดรับในแอป (ช่องทางยังต้องกดเอง ระบบบอกแค่ว่าชีทลงอะไร)
- ยอดกระดาษไม่ตรง = ไม่ให้ผูก (ตามแอปเดิม) + ปุ่มส่งให้ออฟฟิศ · เลขซ้ำวันเดียวกัน = ยืนยันคนละใบได้พร้อมเหตุผล + ธง (เล่มบิลต่างเล่มอาจเลขชน)
- รับเงินเกินยอดค้าง = บล็อก แต่มีทาง "รับเท่ายอดค้าง + แจ้งส่วนเกิน" (ธง) · ยอดที่รับตั้งต้นเป็นยอดค้างเต็ม (แบบแอปเดิมที่ติ๊กบิลแล้วกดช่องทาง) แก้เป็นรับไม่เต็มได้ · วันที่รับตั้งต้น "วันนี้"
- PIN ที่ตั้งจากแอปใหม่ = 4 หลัก (แป้น PIN ของแอปใหม่ส่งเองที่ 4 หลัก) · ตั้ง PIN ใหม่ = แอปเดิมต้องเข้าใหม่ด้วย
- ชื่อชนิดราคา = `ราคาโรงงาน` / `ราคาหน้าร้าน` / `ราคาไม่รวมฝา` (ตรงกับที่โมดูลออฟฟิศอ่าน)
