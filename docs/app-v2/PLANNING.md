## 2. หลักออกแบบ

1. **แผนเดียว** — ตั้งต้นจากแผนสายส่ง → ระบบแตกเป็นขวดที่ต้องมี → ใบงานเป่า → ใบงานสกรีน · คนปรับได้ทุกขั้น ตัวเลขชุดเดียวกันทุกทีม
2. **นัดส่งได้คิวก่อนของจอง** — ของจองยังอยู่ ไม่ตัดเอง แต่กำลังผลิตไปที่งวดที่นัดแล้วก่อน
3. **ขวดขายดีมีกันชน** — สต๊อกขั้นต่ำต่อสเปก (เริ่มที่ 250 คอสั้นใส/น้ำเงิน) ใบงานเป่าเติมให้เอง
4. **เครื่องหยุด = รู้ผลกระทบ** — จอดพร้อมสาเหตุระดับชิ้นส่วน → งวดไหนเสี่ยงไม่ทัน
5. **นอกแผนทำได้ + เหตุผล + ประวัติ + นับครั้ง** (PALM-WAY §2 ข้อ 5) — ขอแทรกไม่บล็อก
6. **ไลน์ = ปุ่มแชร์ให้คนกดส่งเอง** (ไม่กินโควตา) · ส่งอัตโนมัติเฉพาะเรื่องด่วนจริง (เช่น เครื่องหลักจอดเกิน 30 นาที) — ทั้งนี้รอคุณปาล์มเคาะ (§5 ข้อ 5)
7. **ข้อมูลโรงน้ำ = ออเดอร์ประจำฝั่ง P&K** — ไม่ผูกระบบ/ชีตของโรงน้ำ (CLAUDE.md: ห้ามปนข้อมูลสองบริษัท)

## 3. ฟีเจอร์ (สถานะเทียบ v2: มี = ใช้ได้เลย · ต่อ = มีฐานแล้ว · ใหม่)

### ออฟฟิศ
- ต่อ — **งวดส่ง** ต่อรายการออเดอร์ 3 แบบ: `fixed` (จำนวนต่อครั้ง × กี่ครั้ง/ทุกกี่วัน) · `as_made` (ทยอยตามที่ทำได้ มีเพดานต่อเที่ยวได้) · `once` (ครั้งเดียวครบ) · งวดที่ส่งไม่ครบ: `fixed` → ส่วนขาดไปรวมงวดถัดไป · `as_made` → ค้างไว้ทยอยต่อ
- ต่อ — วันส่งต้องเลือกเอง (สัปดาห์นี้ / สัปดาห์หน้า / ไม่รีบ / ระบุวัน) เลิก +10 วันอัตโนมัติ
- ใหม่ — สถานะ **จอง** (ยังไม่มีงวดนัด) กับ **นัดส่งแล้ว** · รายชื่อของจองค้างเกิน N วัน ให้โทรยืนยัน (ไม่ตัดเอง · N = ค่าตั้ง)
- ใหม่ — เลื่อนวันส่ง/งวด = เลือกสาเหตุ (ลูกค้าขอเลื่อน · ขวดไม่พอ · เครื่องเสีย · สกรีนไม่ทัน · รถเต็ม · อื่น ๆ+เหตุผล) → ตาราง `reschedule_events`
- ใหม่ — ออเดอร์ประจำโรงน้ำ (ยอดใช้ต่อสัปดาห์ต่อสเปก) เข้าแผนเหมือนลูกค้า
- ใหม่ (หลังขั้น 3) — วันเร็วสุดที่ทำได้ตอนรับออเดอร์ (สต๊อก + งานค้าง + กำลังเครื่อง)

### ผู้จัดสายส่ง (กระดานสายส่ง 7 วัน)
> **แบบที่ทีมใช้จริง (คุณปาล์มเล่า 19 พ.ย.)**: หัวหน้าทีมสกรีนจัดเอง (จึงรู้ว่าควรสกรีนอะไรวันไหน) + ผู้ช่วย 1 คน · หน้าตาเป็น **ปฏิทินเรียง 7 วัน**
> แต่ละวัน **หมุดสาย** ไว้ (เช่น แพร่ · วังชิ้น · เถิน · ลำพูน · แจ้ห่ม–เมืองปาน) · **อำเภอเมืองส่งได้เกือบทุกวัน** ไม่ต้องหมุด
> ในช่องวันมีแค่ **ชื่อลูกค้า · ลักษณะสินค้า · จำนวน** → หน้าจอใหม่ต้อง **หน้าตาเดียวกับปฏิทินนี้** (ลอกของที่คนคุ้นมือ) ไม่ใช่ตารางวัน × รหัสสาย
> · ชื่อสายในปฏิทินเป็นชื่อพื้นที่ ส่วนทะเบียนลูกค้ามีรหัส 111–121 / 211–215 → ต้องมีตารางจับคู่ ชื่อสาย ↔ รหัส (ถามหัวหน้าทีมสกรีน)
- ต่อ — หน้าเส้นทางของ v2 (`deliver.board`) → **ปฏิทิน 7 วัน**: หัววันมีชิปสายที่หมุด (เมือง = ทุกวันเป็นค่าตั้งต้น) · การ์ดในวัน = ลูกค้า · สินค้า · จำนวน · แตะการ์ดย้ายวัน · ถุงต่อคันรถ
- ใหม่ — **ขวดที่ต้องมี** ต่อสเปกต่อวัน = Σ งวดวันนั้น − (สต๊อก A ขวดเปล่า + ขวดสกรีนแล้วสีนั้น + งานที่เปิดรอบอยู่) → ต้องเป่า/สกรีนก่อนวันส่ง 1 วัน
- ใหม่ — สีต่องวด: พร้อม / ทันตามแผน / เสี่ยง · "ประกาศแผน" = เก็บฉบับ (`weekly_plans` + `plan_lines`) · แก้หลังประกาศ = เหตุผล + นับ

### หมุดลูกค้า (ต้องมีก่อนกระดานสายส่ง — จุดอ่อนข้อมูลที่คุณปาล์มชี้ 19 พ.ย.)
ทะเบียนลูกค้าเดิม: ช่องลิงก์แผนที่ว่างทั้งหมด · ราว ๆ ครึ่งมีรหัสสาย · ลูกค้าที่เพิ่มช่วงหลังมีอำเภอ/ตำบลแต่ไม่มีรหัสสาย · ส่วนหนึ่งไม่มีอะไรเลย
1. **วันแรก ไม่ต้องเก็บเพิ่ม** — เรียนตาราง อำเภอ → สาย จากลูกค้าที่มีทั้งสองช่อง (เช่น วังชิ้น = 217 · เถิน/แม่พริก = 115 · เมืองปาน = 119) แล้วเติมสายให้รายที่มีแค่อำเภอ (เป็น "แนะนำ" ให้คนยืนยัน ไม่เขียนทับ) · หมุดประมาณ = จุดกลางตำบล/อำเภอ
2. **หมุดจริงเก็บเองตอนส่งของ** — คนขับกด "ส่งแล้ว" ที่ร้านที่ยังไม่มีหมุด → แอปถาม "ปักหมุดร้านนี้" แตะเดียวใช้ GPS มือถือ (ไม่บังคับ) · ส่ง 2–4 สัปดาห์ ลูกค้าที่ซื้อประจำจะมีหมุดครบ
3. **ลิงก์แผนที่ที่ลูกค้าส่งในไลน์** — ออฟฟิศวางลิงก์ในหน้าลูกค้า แอปแกะพิกัดเอง
4. มีหมุดแล้ว: ปฏิทินสายส่งแนะนำสายให้ · มุมมองแผนที่ให้คนจัดสายดูว่าลูกค้าวันเดียวกันอยู่ใกล้กันไหม (ดูแบบแผนที่ของแอปเซลส์โรงน้ำ — ยกเฉพาะแนวคิด ห้ามผูกข้อมูลข้ามบริษัท)

### ทีมเป่า + ฉีดหลอด
- มี — ผัง · รอบเครื่อง · จอด/โมลด์ · งานรอผลิต · สต๊อก A/B
- ใหม่ — **ตาราง โมลด์ × เครื่อง** (`mold_fits`: โมลด์ · เครื่อง · ใบต่อรอบ · ใบ/ชม.มาตรฐาน (เริ่มจากค่ากลางของประวัติ) · ชม.เปลี่ยนโมลด์)
- ใหม่ — **ใบงานพรุ่งนี้ต่อเครื่อง** ที่ระบบเสนอ: เป้าเป็นถุง · ลำดับสี (ใส → สี) · รวมงานโมลด์เดียวกันให้เปลี่ยนน้อย · เติมสต๊อกขั้นต่ำ · คนที่ต้องใช้ · หัวหน้าเป่าปรับ/ยืนยัน → แชร์ลงไลน์ (แทนข้อความ "พรุ่งนี้ฮีตไฟเป่า…")
- ใหม่ — **ขอแทรก** (`insert_requests`: สเปก · ถุง · ต้องใช้วัน · ออเดอร์/ลูกค้า · เหตุผล · คนขอ) → รับแตะเดียว → โชว์งานที่เลื่อน · นับต่อสัปดาห์
- ต่อ — เป้า vs ทำได้บนผัง · หลอดที่ต้องฉีด (ตัดหลอดตอนเป่า — ต้องมียอดยกมาหลอดก่อน)

### ช่าง
- ต่อ — สาเหตุจอดระดับชิ้นส่วน (ก้ามปู · รางหลอด · โมลด์ค้าง · ลม · น้ำเย็น · ไฟ/คอนแทคเตอร์ · ฮีตเตอร์ · อื่น ๆ) + **ช่างกดซ่อมเสร็จ** (ชื่อช่าง · เวลา) — ต่อจาก `run.stop`/`run.resume`
- ใหม่ — กระดานเสียซ้ำ (ชิ้นส่วน × เครื่อง × ครั้ง × ชม. ต่อสัปดาห์)
- ใหม่ — ทะเบียนอะไหล่สำคัญ (`spare_parts`: เครื่อง · ชิ้น · ขั้นต่ำ · คงเหลือ · ซื้อ/สั่งทำที่ไหน · รอกี่วัน) ต่ำกว่าขั้นต่ำ = ธง
- ใหม่ — เช็คลิสต์ประจำวัน/สัปดาห์ (วาล์วลม · ชิลเลอร์ · ปั้มลม · โซ่เครื่องสกรีน) · เวรช่างต่อกะ → ใบงานเตือนเมื่อมีกะค่ำแต่ไม่มีช่าง
- ต่อ — ปั้มลม/ชิลเลอร์บนผัง (มี AIRT1–6 · WATER1 แล้ว) หยุดแล้วนับเครื่องเป่าที่หยุดตาม · ภายหลังตัววัดแรงลม/มิเตอร์ (`devices`)

### ทีมสกรีน + แพ็ค
- มี — คิว · แตะทีม + เสร็จ · ลงจำนวนภายหลัง · สต๊อกขวดเปล่าออก/ขวดสกรีนเข้า
- ใหม่ — ใบงานสกรีนต่อทีมต่อวัน (จากแผนสายส่ง · เรียงสีให้เปลี่ยนบล็อกน้อย · เฉพาะงานที่ขวดเปล่าพร้อม)
- ต่อ — จอดเครื่องสกรีน S1–S8 ปุ่มเดียวกับเครื่องเป่า
- ใหม่ — ป้ายถุง (สเปก · สี · วัน · ทีม · ใบต่อถุง) ไล่ย้อนเคลม · ที่เก็บของ (โรง 1 / โรง 2 / โรงน้ำ · จุกี่ถุง)

### Checker + ขนส่ง
- มี — ขึ้นรถ/ส่งแล้ว/บางส่วน/ไม่ได้ · เอาลง · ย้ายคัน · ใบส่งของ (ไม่มียอดเงิน)
- ใหม่ — เช็คของพร้อมต่อคัน เย็นก่อนวันส่ง · พิมพ์ทั้งคัน · ต่อ — Checker ติ๊กตามใบ ไม่ตรง = เหตุผล

### QC · คนและกะ · ประธาน
- ต่อ — สาเหตุของเสียแบบชิปตอนปิดรอบ (บุบ/บี้ · ก้นนูน · คอเอียง · คอไหม้ · ตะเข็บ) · ใหม่ — สุ่มตรวจต่อกะ · เคลมผูกป้ายถุง
- ใหม่ — คนที่ต้องใช้ต่อกะ vs คนที่มา (อ่านวันลาจาก P&K HR อย่างเดียว) · ขอยืมคน/OT/กะดึกเป็นรายการ — **ไม่ทำลงเวลา** (PALM-WAY §8: ระบบลงเวลาในแอปทีมงานถูกตัดแล้ว)
- ใหม่ — ตัววัดรายสัปดาห์: ส่งตรงเวลาครบจำนวน % · เลื่อนตามสาเหตุ · เครื่องหลักเดิน % ของเวลาที่วางแผน · ครั้งที่แทรก · สต๊อก 250 คอสั้นพอกี่วัน · งานค้างกี่สัปดาห์ต่อสเปก

## 5. คุณปาล์มเคาะแล้ว (19 พ.ย.)

1. **มัดจำไม่บังคับ** (ช่องลงมัดจำมีไว้ ไม่เตือน) — ฟีเจอร์มัดจำเพิ่มเติมค่อยว่ากันทีหลัง
2. **มีมัดจำ = หักในบิลเลย** (บิลแรก ๆ ของออเดอร์จนหมด · ส่วนเกินค้างไว้บิลถัดไป · ยกเลิกออเดอร์ที่ยังมีมัดจำ = ธงให้คนตัดสินเรื่องคืนเงิน)
3. **ขวดไม่พอ ใครได้ก่อน = ตามงวดที่นัด/คิวไว้ก่อน** (งวดใกล้สุด → ลงคิวก่อน → ของจองท้ายสุด) **แต่ปรับมือได้** (ดันขึ้น/เลื่อนลง + เหตุผล + ประวัติ)
4. ของจองค้าง **14 วัน** → ขึ้นรายชื่อให้โทรยืนยัน
