# ระบบดีไซน์ โรงขวด P&K v2

วิธีเดียวกับระบบดีไซน์ "ละกอน" ของโรงน้ำ (`origin-hq/design-system/`): tone ramp 10–99 คำนวณใน OKLCh แล้วตรึงเป็น hex
(ไม่พึ่ง `oklch()` ของเบราว์เซอร์) + ตรวจคอนทราสต์ทุกคู่ที่ใช้จริงในตัวสคริปต์ — ต่างกันแค่ **สีประจำบริษัท = แดงอิฐ `#B24A4F`**
(สีเดิมของแอปโรงขวด `index.html :root --brand`) · ไม่ใช้ธีมกระจก (โรงน้ำรื้อแล้ว)

| ไฟล์ | คืออะไร |
|---|---|
| `gen_tokens.py` | ต้นฉบับ — ramp 5 ตระกูล + สีตามหน้าที่ (สว่าง/มืด) + ระยะ/ตัวอักษร/เงา/จังหวะ · ตรวจ 24 คู่ × 2 โหมด (WCAG AA) ไม่ผ่าน = exit 1 |
| `_color_math.py` | คณิต OKLCh ↔ sRGB + คอนทราสต์ (ยกจากโรงน้ำไม่แก้) |
| `tokens.css` | ผลลัพธ์ (ห้ามแก้มือ) — สคริปต์เขียนสำเนาไป `v2/web/assets/tokens.css` ด้วย |

```bash
python3 v2/design/gen_tokens.py          # สร้างใหม่ + ตรวจคอนทราสต์
python3 v2/design/gen_tokens.py --check  # CI: ตรวจว่า tokens.css ตรงกับสคริปต์
```

## สี (ใช้ "สีตามหน้าที่" เท่านั้นในหน้าเว็บ)

| token | ใช้ทำอะไร |
|---|---|
| `--bg` `--surface` `--surface-2` `--sunken` | พื้นแอป · การ์ด · พื้นรอง · ช่องกรอก |
| `--ink` `--ink-2` | ตัวหนังสือหลัก · รอง (ผ่าน 4.5:1 บนทุกพื้น) |
| `--line` `--edge` | เส้นแบ่ง (ตกแต่ง) · ขอบของที่กดได้ (≥ 3:1) |
| `--brand` `--on-brand` `--brand-soft` `--brand-ink` `--brand-tint` | แดงอิฐ: ปุ่มหลัก/เมนูที่เลือก/ลิงก์ |
| `--ok` `--warn` `--bad` (+ `-soft` `-ink`) | **สถานะเท่านั้น** ความหมายเดียวกับโรงน้ำ: เขียว = เดินอยู่/สำเร็จ · อำพัน = ต้องดู/ค้าง/ใกล้กำหนด · แดงเข้ม = ผิดปกติ/เลยกำหนด/ยอดไม่ตรง |
| `--focus` | วงโฟกัสคีย์บอร์ด |

สถานะ = **สี + คำ + สัญลักษณ์** เสมอ (`ui.pill()`) — ไม่ใช้สีอย่างเดียว (แดงอิฐกับแดงสถานะใกล้กัน จึงต้องมีคำ+ไอคอนกำกับ)

## ตัวอักษร · ไอคอน · การเคลื่อนไหว

- หัวข้อ/ตัวเลข **Anuphan** · เนื้อความ **Sarabun** · ตัวเลข `tabular-nums` · line-height ไทย 1.5–1.7
- ไอคอนเส้นชุดเดียว `v2/web/assets/icons.svg` (เรียก `ui.icon('ชื่อ')`) — **ห้ามอีโมจิ** (`tools/check.mjs` ตรวจ)
- ปุ่มแตะ ≥ 44px (`--tap`) · ปุ่มหลักในแผ่น 56px (`--tap-lg`) — เทสต์หน้าจอวัดทุกปุ่ม
- motion 120/200/320ms · `prefers-reduced-motion` = ปิดหมด (ทั้งใน tokens และ app.css)
- โหมดมืด: ตามเครื่อง หรือเลือกเองในเมนูบัญชี (สว่าง/มืด/ตามเครื่อง) — ทุกคู่สีผ่าน AA เหมือนโหมดสว่าง
