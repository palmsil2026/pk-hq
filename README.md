## ติดตั้งครั้งแรก (คุณปาล์มทำ ~10 นาที)

1. ล็อกอิน `palm.work2026@gmail.com` → [script.new](https://script.new) → ตั้งชื่อ **P&K System** → วาง `gas/Code.gs` ทั้งไฟล์
2. รัน `setupPkSystem()` (สร้างชีต `PKSystem` + ตั้ง `PK_SHEET_ID` เอง — รันซ้ำได้ ปลอดภัย)
   > 🔁 **ทุกครั้งที่วางโค้ดรุ่นใหม่ทับ ให้รัน `setupPkSystem()` ก่อน** — มันเติมแท็บ/คอลัมน์ใหม่ให้ชีตเดิม (ต่อท้ายเท่านั้น ไม่แตะข้อมูลเก่า)
   > ตั้งแต่ `2026-08-30h` ฟังก์ชัน `seed*`/`import*` เรียกให้เองอัตโนมัติแล้ว จะลืมก็ไม่พัง
3. Script properties เพิ่ม: `PK_EXEC_KEY` (รหัสผู้บริหาร — ตั้งยาว ๆ เดายาก) และ `PK_KEY` (รหัส API สำรองสำหรับสคริปต์/แชทการเงิน — พนักงานไม่ใช้)
4. รัน `importLegacyAccounting()` → ดึงบิล/ลูกหนี้/ลูกค้าเก่าจากสแนปช็อต "ระบบบัญชี"
   · **`seedProducts()`** → ทะเบียนสินค้า 29 รายการลงแท็บ `Products` · รันซ้ำได้ ไม่เบิ้ล
   · **`importLegacyOrders()`** → ออเดอร์เก่า 136 ใบจากชีต "Order" ของ AppSheet (พร้อมแกะหมายเหตุมือเป็นช่องจริง) · เป็นประวัติล้วน ไม่สร้างงานผลิต ไม่แตะสต๊อก · รันซ้ำได้ ไม่เบิ้ล
   · **`importLegacyCustomers()`** → ทะเบียนลูกค้าเดิม 225 ราย พร้อมเส้นทางส่ง/อำเภอ/เบอร์ · ของเดิมไม่ถูกทับ เติมเฉพาะช่องที่ว่าง
   · **`seedMachines()`** → ทะเบียนเครื่องฉีด 12 ตัว (PET 1–10 · SHE230G · LG17-228)
5. Deploy → New deployment → **Web app** (Execute as: Me / Anyone) → คัดลอก URL
6. ~~เอา URL วางแทน `PASTE_PK_GAS_WEBAPP_URL_HERE` ใน `index.html` + `exec/index.html`~~ ✅ **ทำแล้ว 30 ส.ค.** (ถ้า deploy ใหม่จน URL เปลี่ยน ค่อยแก้ `const GAS_URL` ในสองไฟล์นั้น)
7. เปิดบอร์ด `exec/?key=รหัส` → **จัดการพนักงาน → เพิ่มพนักงาน** (ชื่อเล่น+PIN) → ให้ทีมล็อกอินแอปหน้าแรกด้วยชื่อเล่น+PIN ของตัวเอง
   (แก้โค้ด GAS ครั้งถัดไป: Manage deployments → ✏️ → New version เท่านั้น + bump `CODE_VERSION`)

## วงจรข้อมูล v2 (ซิงก์กันหมดอัตโนมัติ)

- ลงออเดอร์ → **เลือกสเปกแบบเดียวกับแอปเดิม** (ประเภท → ขนาด → คอ/ทรง/สี → สีสกรีน/ฝาสี) · ใส่**จำนวนถุง** ระบบคูณ "ใบต่อถุง" เป็นจำนวนใบให้เอง (ขวด 250 = 252 ใบ/ถุง ฯลฯ ถอดจากออเดอร์จริง) → เกิด **งานผลิตแยกรายสินค้า** (+งานสกรีนถ้ามี) อัตโนมัติ
- ทีมผลิต/สกรีน กด "ลงผลผลิต" — แยกผล **3 ทาง: ดี / เกรด B / ของเสีย** (+สาเหตุ) พร้อมเลือก**เครื่อง**ที่ใช้ → ของดีบวกเข้าสต๊อกเอง · **เกรด B นับแยก ไม่บวกเข้าสต๊อกของดี** · ของเสียฝั่งสกรีนหักสต๊อกเอง
- คนส่งของกด "ส่งรอบนี้" (ส่งบางส่วนได้) → **หักสต๊อกตามจำนวนส่งจริง** + สถานะออเดอร์เดินเอง
- ออกบิลจากออเดอร์ / บิลอิสระ (ขายหน้าโรง — หักสต๊อกที่บิล) → เครดิตเข้าใบวางบิล → เก็บเงิน
- **ทุกการกระทำลง ActivityLog ว่าใครทำอะไรเมื่อไหร่** (ตัวตนจาก PIN ที่ล็อกอิน ไม่ใช่พิมพ์เอาเอง)
- ยกเลิกออเดอร์ = งานผลิต/สกรีนที่เหลือถูกยกเลิกตาม · ยกเลิกบิลต้องใส่เหตุผล + คืนสต๊อกให้ (บิลอิสระ)

## ดูย้อนหลัง (เพิ่ม `2026-08-30i`)

- **แตะออเดอร์ในลิสต์ไหนก็ได้** → เปิดรายละเอียดเต็ม: สเปกทุกรายการ (กี่ถุง×กี่ใบ) · ส่งไปแล้ว/เหลือเท่าไหร่ · ความคืบหน้างานผลิต+สกรีน (ดี/เกรด B/เสีย/สาเหตุค้าง) · ประวัติการส่งของ · บิล · **หมายเหตุลูกค้า** (เช่น "เงินไม่ดีให้สั่งทางออฟฟิต") + เส้นทาง/เบอร์
- **แท็บ ประวัติ → ประวัติออเดอร์ของลูกค้า** — พิมพ์ชื่อลูกค้า เห็นทุกออเดอร์ย้อนหลัง (รวมที่ import จาก AppSheet เดิม) + สรุปกี่ออเดอร์/กี่ใบ/กี่บาท · จับคู่ชื่อแบบหลวม เพราะออเดอร์เก่ามักมีชื่องานพ่วงท้ายชื่อลูกค้า
- **แท็บ ประวัติ → ประวัติงานทีมสกรีน** — เลือกช่วงวัน เห็นงานสกรีนทั้งหมด + ยอดดี/เกรด B/เสีย และ**ล็อกรายครั้ง**ว่าใครลงเมื่อไหร่ เสียเพราะอะไร

## กติกาข้อมูล (ให้ทุกแชทอ่าน — รวมแชท "แอพการเงินโรงขวด")

- สเปรดชีต **`PKSystem`** คือฐานเดียวของ P&K: `Customers` `Products` `Orders` `Production` `ScreenJobs` `Bills` `Statements` `PriceHistory` `Settings`
- **เงินรับจริง/ลูกหนี้ อ่านจากแท็บ `Bills`** (สถานะ: ชำระแล้ว / ค้างชำระ / วางบิลแล้ว · ประเภท: เงินสด / เครดิต) — ใบวางบิลอยู่ `Statements`
- แชทการเงินเพิ่มแท็บใหม่ได้ (เช่น `Expenses`) แต่**ห้ามเปลี่ยนชื่อคอลัมน์/ความหมายของ `Bills` และ `Statements`** — ถ้าจำเป็นให้จดใน STATUS.md แล้วบอกกันก่อน
- หาคอลัมน์จากหัวตารางเสมอ อย่าอ้างเลขคอลัมน์ตายตัว
- **ราคาสินค้า**: ประธานใหญ่ปรับผ่านบอร์ดบริหารเท่านั้น (`pkPriceSet` — ล็อกด้วย `PK_EXEC_KEY`) ทุกครั้งลง `PriceHistory` · หน้ารับออเดอร์เติมราคากลางให้อัตโนมัติแต่แก้มือได้ (ราคาจริงต่อรองหน้างานได้)

## ความทนทานที่ใส่ไว้แล้ว (ผ่านรีวิว adversarial 93 ประเด็น 30 ส.ค.)

- **กันกดซ้ำ/ยอดเบิ้ล**: ปุ่มล็อกระหว่างรอ + ทุก mutation มี request-id — server จำ 6 ชม. กดซ้ำ/คิวส่งซ้ำได้ผลเดิม ไม่บันทึกซ้ำ
- **คิวออฟไลน์**: ลงเวลา/ผลผลิตตอนเน็ตหลุดเก็บไว้ส่งเอง (เวลาที่บันทึก = เวลาที่กดจริง) ผูกกับคนกด รายการที่ server ปฏิเสธถูกข้ามไม่บล็อกคิว ส่งอัตโนมัติเมื่อเน็ตกลับ
- **สิทธิ์**: งานเงิน (ออกบิล/รับชำระ/ยกเลิกบิล/ใบวางบิล) และปรับยอดสต๊อก จำกัดแผนกออฟฟิศ/บริหารที่ตัว API ไม่ใช่แค่ซ่อนปุ่ม · PIN ไม่มีทางหลุดออก API · `rotateExecKey()` หมุนรหัสผู้บริหารได้จาก editor
- **ตัวเลขไม่โกหก**: ส่งของ/สถานะคิดเป็นยอดรวมต่อสินค้า (สินค้าเดิมหลายบรรทัดไม่นับเบิ้ล) · เวลาเข้างานกันชีตแปลงเป็นปี 1899 · บอร์ดอ่านช่วง 30 วันจริงไม่ใช่จำนวนแถวตายตัว · สต๊อกติดลบเด้งเตือนบนบอร์ด · import รันซ้ำไม่เบิ้ลบิล
- ยังไม่ทำ (จดไว้เฟสหน้า): BOM ตัดวัตถุดิบอัตโนมัติ, ปุ่มแก้ออเดอร์ใน UI (backend `pkOrderEdit` พร้อมแล้ว), บิลตามงวดส่ง, รวมลูกค้าชื่อซ้ำ
